# RepoPilot-AI

Panel admin untuk mengelola video di farming21/indonesia.

## Fitur
- Tambah video baru
- Edit video yang sudah ada
- Hapus video
- Upload cover image
- Validasi otomatis
- Preview sebelum publish

## Cara Menggunakan
1. Buka https://farming21.github.io/RepoPilot-AI/
2. Isi form dengan data video
3. Upload cover image (opsional)
4. Klik "Publish Video"
5. Sistem akan otomatis update videos.json di GitHub

## Konfigurasi
Edit file `index.html` dan ubah `WORKER_URL` dengan URL Cloudflare
